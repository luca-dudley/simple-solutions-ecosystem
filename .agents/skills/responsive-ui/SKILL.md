# Responsive Design & Theme Tokens
1. **Design System**: Mobile-first Tailwind CSS. Base classes target mobile viewports (`w-full`), expanding with `sm:`, `md:`, `lg:`.
2. **Unified Navigation**: Tools and portal pages must share consistent top-bar branding and slide-out mobile drawer components.
